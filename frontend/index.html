⚠ Erros léxicos encontrados

Um erro léxico ocorre quando o scanner encontra um caractere ou sequência que não pertence ao vocabulário da linguagem. O scanner continua processando o restante do código, acumulando todos os erros de uma vez.

LinhaCol.LexemaMensagem

🔍 Tokens identificados

Um token é a unidade mínima com significado para a linguagem. O lexema é a sequência de caracteres que forma o token no código-fonte. O scanner percorre o código da esquerda para a direita, agrupando caracteres e classificando cada grupo em uma categoria.
